## ⚡️ Kurulum & Çalıştırma (Installation & Usage)

### Ön Gereksinimler
- GCC veya Clang derleyicisi
- Make

### Hızlı Başlangıç

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/[YOUR_USERNAME]/[PROJECT_NAME].git
   cd [PROJECT_NAME]
   ```

2. Projeyi derleyin:
   ```bash
   make
   ```

3. Uygulamayı çalıştırın:
   ```bash
   ./[PROJECT_NAME] [ARGÜMANLAR]
   ```
